TeslaBatteryBLE

An Android app that talks to a Tesla over Bluetooth LE: battery state, charge state, and a local history. Keys are enrolled on the car; there is no account and no server.

Install

TeslaBatteryBLE is in beta. The rolling preview is rebuilt from main on every push.

GitHub Releases (preview APK)

  1. Open the rolling preview release.
  2. Download the latest APK.
  3. Open the APK on your Android device and allow installation from the browser or file manager.

Preview APKs are debug builds, signed with the same key as releases and sharing their app ID, so a later release installs over a preview in place.

Obtainium (auto-updates)

  1. Open Obtainium and tap Add App.
  2. Enter https://github.com/dzid26/TeslaBatteryBLE.
  3. Obtainium tracks stable releases by default; enable Include prereleases only if you want the rolling preview channel.
  4. Install and let Obtainium keep it updated.

No stable release has shipped yet, so the preview is currently the only channel.

Privacy

The app has no internet permission; it only talks to the car over Bluetooth, and keys and history stay on the device. The full privacy statement is in the repository.
